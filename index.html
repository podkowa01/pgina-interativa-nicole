function mostrar(etapa) { const conteudo = document.getElementById("conteudo"); if (etapa === "leitoes") { conteudo.innerHTML = `

🐷 Chegada dos Leitões

Os leitões chegam à granja com aproximadamente 21 dias de idade. Eles recebem ração adequada, água limpa e acompanhamento diário para crescerem de forma saudável.

`; } else if (etapa === "creche") { conteudo.innerHTML = `

🏠 Saída para a Creche

Após o período inicial, os leitões vão para a creche. Nessa fase eles continuam crescendo com alimentação balanceada e recebem todos os cuidados necessários.

`; } else if (etapa === "abate") { conteudo.innerHTML = `

🚛 Saída para o Abate

Quando atingem o peso ideal, os suínos seguem para o frigorífico. Após o processamento, a carne é distribuída para supermercados e açougues.

`; } }
